# lab-5
1. Функция sequentialBlur обрабатывает изображение построчно в одном потоке, что медленно
   * Структура Color - хранит компоненты цвета (r, g, b) как unsigned char (0-255)
   * Функция sequentialBlur:
    Принимает изображение как вектор векторов Color
    Создает такое же по размеру изображение для результата
    Для каждого пикселя:
    Собирает значения из окна 3x3
    Вычисляет среднее значение
    Записывает результат
    * main():
     Создает большое изображение (2000x2000 пикселей)
     Заполняет его 
     Выводит время работы
2. Функция parallelBlurThreads использует несколько потоков для одновременной обработки разных частей изображения, значительно ускоряя процесс.
   * В parallelBlurThreads изображение делится на горизонтальные полосы (по строкам)
    Каждый поток получает свой диапазон строк (start_y до end_y) для обработки
    * threads.emplace_back создает и запускает потоки

t.join() ожидает завершения всех потоков перед возвратом результата
ИТОГО: Sequential blur time: 0.892016 s
       Parallel blur time: 0.197881 s
